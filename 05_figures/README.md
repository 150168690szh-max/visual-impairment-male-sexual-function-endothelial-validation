# Figures

This directory contains figures generated from the reproducible analyses.

## Contents

### GSE206528
Figures related to human corpus cavernosum single-cell RNA-seq analysis, including:
- ACKR1-associated endothelial identity;
- SELE-associated endothelial activation;
- donor-level endothelial-state comparisons;
- key-gene DotPlots;
- endothelial subtype summaries.

### GSE261085
Figures related to human corpus cavernosum spatial transcriptomics, including:
- ACKR1/SELE spatial relationships;
- neighbourhood enrichment;
- quadrant spatial organisation;
- endothelial-state annotation;
- cluster and marker visualisation.

### GSE2457
Selected quality-control and expression-analysis figures from diabetic rat penile-tissue transcriptomics.

### ED GWAS
Genome-wide association results, including Manhattan plots.

### Cross-dataset analyses
Figures supporting transfer of endothelial-state signatures from GSE206528 to GSE261085.

### `marker_validation_figures/`
Spatial expression plots for endothelial marker genes used to support spatial annotation and validation.

## Notes

Large raw objects and intermediate diagnostic figures are not included in this public repository.

Selected quality-control and development-stage figures were retained outside the public GitHub archive.
