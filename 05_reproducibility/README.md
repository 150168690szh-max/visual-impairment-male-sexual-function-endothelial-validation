# Reproducibility materials

This directory contains metadata, audit tables, software information, and manuscript-supporting summaries used to verify the reproducible analyses.

## Structure

### `environment/`
Data-source documentation, software versions, session information, GEO inventory, and processed-object size summaries.

### `audits/`
Audit tables for GSE206528 and GSE261085, including:
- sample and cell counts;
- cell-type and endothelial-state counts;
- final metadata;
- object-level audit summaries;
- spatial spot counts and QC summaries.

### `TableS8/`
Final tables supporting Supplementary Table S8 and manuscript reporting.

Only final verified Table S8 outputs are retained in the public repository.

## Notes

Large processed R objects are not included in GitHub.

Raw data remain available from their original public repositories.

Software package versions and session information are included to support reproducibility.
